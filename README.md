# Soans Farm Plant Catalogue

The Soans Farm Plant Catalogue is a focused Next.js MVP for browsing the farm's documented plant collection.

## Features

- Search by plant number, common name, scientific name, or alternate name
- Open plant records in an adjustable bottom sheet
- Resize the sheet with touch, mouse, or keyboard controls
- Navigate to adjacent plant records from the detail sheet

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/catalogue` in a browser. The root path redirects there.

## Production checks

```bash
npm run lint
npm run typecheck
npm run build
```
